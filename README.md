# 覚えろ！ 県庁所在地

47都道府県の県庁所在地を、文字入力と地図で繰り返し覚えるモバイル対応ブラウザゲーム。

**遊ぶ： https://yo4e.github.io/ken-geme/**

## 遊び方

1. 「都道府県 → 県庁所在地」または逆向きを選んで、はじめる。
2. 漢字と「市」「区」、逆向きでは「都」「道」「府」「県」まで入力する。さいたま市はひらがなの正式表記。前後の空白と全角・半角の互換文字は正規化するが、読み仮名・市区の省略・別名は正解にしない。
3. 間違えたら「答えを見る」。地図と答えを確認し「次の県へ」。そのカードは未正解のまま残りにランダム再投入される。ほかのカードがあれば直後の連続出題は避ける。最後の1枚は再挑戦する。
4. **自分で47枚すべてに正解したらクリア。** 答えを見るだけではクリア数は増えない。

時間は解答中だけ計測。正解、不正解、答えの確認中は停止し、次の問題へ進むと再開。解答中にバックグラウンドへ移っても経過時間に含める。モード別最短記録を、このブラウザのlocalStorageに保存する。

再読み込みは途中のプレイを終了する。最短記録は保持する。保存が使えない場合や容量不足でもゲームを続行でき、保存できなかったことを表示する。ログイン、アカウント、バックエンド、解析サービス、広告はない。名前や回答履歴などの個人情報を収集しない。フォント・地図・画像はサイト内配信。

## 記録のシェア・キーボード・ホーム画面

クリア画面の「記録をシェア」で、今回のタイム・モード・答えを見た回数・ゲームのURLを共有する。対応端末ではOSの共有画面を開き、非対応ならコピーする。コピーできない場合は文章を選択して手動でコピーできる。キャンセル時は何もコピーせず、自動投稿もしない。

PCでは正解・答えの確認画面でEnterを押すと次へ進む。IMEの変換確定中、Enter長押し、回答直後のイベントでは進めない。不正解画面は従来どおり「答えを見る」で確認する。

ブラウザ用favicon、iOS用180pxアイコン、Androidなどのホーム画面用192/512pxアイコンとmanifestを同梱。ブラウザの「ホーム画面に追加」から保存できる。通信できる環境で遊ぶ構成であり、オフライン対応は追加していない。アイコン・manifest・共有URLは配置ディレクトリに追従し、将来のサブディレクトリ移設にも対応する。

よろずコム・よろずミニゲームへのリンクは右上のメニュー内にまとめる。ゲーム画面は独立したデザインを保つ。

`node scripts/prepare-icons.mjs` はローカルサーバー起動後に、既存のNoto Sans JPとPhosphorのSealからアイコンを再生成する。

## 東京都の扱い

このゲームは「都庁がある区」を問い、**新宿区**を正解とする。J-LISの庁舎住所および「東京都庁の位置を定める条例」に基づく。地図帳などに見られる「東京」という表記は地域の示し方が異なるため、誤解を避ける説明を開始画面と東京都の答え画面に表示する。東京市は現在存在しない。

## 開発・検証

Node.js 22以上。React + Vite。純粋な状態遷移ロジックと画面を分離。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4178
npm test
npx playwright install chromium webkit
npm run test:e2e
npm run build
```

`dist/client` が静的な公開対象。GitHub Actionsでテスト・ビルド後、GitHub Pagesへ公開する。サイトは相対パスなので将来別のサブディレクトリにも配置できる。

`npm run maps` で原図から47県の着色地図を再生成。`sources/food-verification.json` は公的な地域別ページとの名称照合結果。ゲームの回答テストはJ-LISとの照合済み一覧に対して検証する。

テスト範囲：47データの一意性・正答・地図ID、誤答→答え→再投入、全問クリア、両モード、保存・再読み込み・保存拒否、IMEイベントとEnterの区別、二重操作、320/390/1280px。日本語IMEのイベントはブラウザで再現するテストであり、すべての実機キーボードでの動作を保証するものではない。

採用3画面との見た目比較：[design-qa.md](design-qa.md)。
